Buying checklist

Tell us whether you test metal, rubber, copper, wire, cable, textile, plastic or another material. Sample dimensions and shape affect grip and fixture selection.

Capacity and test method

Frequently asked questions

How do I choose the correct capacity?

Start from your material strength and sample size. If unsure, send the sample type and expected test standard so we can advise a practical machine range.

Is a universal testing machine the same as a tensile testing machine?

A universal testing machine can often perform tensile, compression, bending and other tests depending on fixtures and software. Tensile testing is one of the main applications.

Can you support older machines?

Send the machine model, capacity, current issue and photo. We can advise whether servicing, parts, calibration support or replacement should be considered.
