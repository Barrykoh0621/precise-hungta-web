## Plain Explanation

### What "ISO scope" Means

ISO scope means the exact services Hung Ta wants to be accredited for.

It is not "we do calibration".

It must be specific:

- What item is calibrated or tested
- What measurement range
- What method or standard is used
- What equipment is used
- What uncertainty or capability can be claimed
- Where the work is performed: in-house, on-site, or both

If the scope is too broad, the workload becomes too heavy. For a 3-person company, the first scope must be narrow and realistic.

## Recommended First Accreditation Direction

Do not start with every instrument.

Start with the services closest to Hung Ta's existing reputation and revenue:

1. Universal testing machine / tensile testing machine verification and calibration support
2. Force / load measurement related to testing machines
3. Load cell calibration support
4. Testing machine service inspection records

Important distinction:

- ISO/IEC 17025 accreditation should be for defined calibration/testing activities.
- Repair, troubleshooting, installation and sales are useful business services, but they are not automatically ISO/IEC 17025 accredited activities.

## Draft First Scope Options

### Option A: Narrowest First Scope

Use this if we want the easiest first accreditation path.

- Field: Mechanical / force-related calibration
- Service: Load cell / force measuring system calibration
- Range: to be confirmed from actual master equipment
- Location: in-house first, on-site later only if procedure and environment control are ready
- Target customers: factories with tensile / universal testing machines

Why this is practical:

- It connects directly to tensile and universal testing machine service.
- It can generate repeat calibration income.
- It avoids claiming too many equipment categories before the system is ready.

### Option B: Testing Machine Verification Scope

Use this if Hung Ta already has method, equipment and technical confidence.

- Field: Mechanical testing machine verification
- Service: Tensile / universal testing machine force verification
- Related item: force indication of testing machine
- Standard/method: to be confirmed from applicable machine verification standard or documented in-house method
- Location: on-site at customer factory

Risk:

- On-site work needs stronger control: environment, method, records, uncertainty, technician competence, and equipment traceability.

### Option C: Broader Mechanical Calibration Scope

Do not start here unless we have equipment and trained personnel.

- Load cells
- Force gauges
- Proving rings
- Torque or dimensional instruments if applicable
- Testing machine verification

Risk:

- Too broad for a 3-person team in the first phase.
- More procedures, uncertainty budgets, reference equipment and competence records are needed.

## Recommended Decision For Hung Ta

Rachel's recommendation:

Start with Option A plus preparation for Option B.

Practical first claim:

Hung Ta is preparing ISO/IEC 17025 capability for force-related calibration and testing-machine verification support.

Do not market as "ISO/IEC 17025 accredited" until accreditation is actually granted.
