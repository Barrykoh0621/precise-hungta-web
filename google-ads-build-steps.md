# Google Ads Build Steps

Use this when setting up the account. Stop before publishing if billing or final approval is not confirmed.

## 1. Account Basics

Goal:

- Leads

Campaign type:

- Search

Networks:

- Google Search Network only

Turn off:

- Display Network
- Search partners for first 14 days
- Auto-apply recommendations

Location:

- Malaysia

Language:

- English

## 2. Campaigns

Create two campaigns and keep both paused until launch approval.

Campaign 1:

- Name: HTI - Universal Tensile Machine
- Daily budget: RM9

Campaign 2:

- Name: HTI - Calibration ISO 17025 Prep
- Daily budget: RM6

## 3. Ad Groups

Campaign 1 ad groups:

- Tensile Testing Machine
- Universal Testing Machine

Campaign 2 ad groups:

- Testing Machine Calibration
- Load Cell Calibration
- ISO 17025 Calibration

## 4. Keywords

Use:

- `google-ads-keywords.csv`

Match types:

- Exact
- Phrase

Do not use broad match in the first month.

## 5. Ads

Use:

- `google-ads-responsive-search-ads.csv`

Important:

- Do not say ISO 17025 accredited yet.
- Safe wording: preparing ISO/IEC 17025 calibration capability.
- Main CTA: Request quotation / Request calibration support.

## 6. Negative Keywords

Use:

- `google-ads-negative-keywords.csv`

Add at campaign level before launch.

## 8. Launch Gate

Only launch when all are true:

- Owner approves launch.
- Billing is checked.
- Daily budget total is RM15.
- Display Network is off.
- Search partners are off for first 14 days.
- Keywords are exact/phrase only.
- Negative keywords are added.
- Landing pages open successfully.

## 9. First Review

Review after 3-4 days:

- Search terms
- Spend
- Clicks
- Phone / WhatsApp / email enquiries
- Irrelevant searches

Add negative keywords immediately when irrelevant searches appear.
