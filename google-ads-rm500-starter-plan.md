# Google Ads RM400-RM500 Starter Plan

Company: HUNG TA INSTRUMENT (M) Sdn. Bhd.

Monthly test budget: RM400-RM500

Recommended setting: RM15/day

Expected 30-day spend: about RM456

## Strategy

Do not spread the first budget across every product category. Start with two highest-value buyer intents:

1. Universal / tensile testing machine buyers
2. Calibration buyers, especially customers interested in ISO/IEC 17025 readiness

## First 30-Day Rules

- Search Ads only.
- Malaysia first; Singapore can be added later if enquiries are relevant.
- Use phrase match and exact match first.
- Check search terms every 3-4 days.
- Add negative keywords immediately when irrelevant clicks appear.
- Do not enable Display Network.
- Do not use broad match in the first month.

## Success Criteria

Continue or increase budget only if at least one of these happens:

- Qualified WhatsApp enquiry
- Phone call from factory, lab, QA or purchasing team
- Email asking for quotation, calibration or machine recommendation
- Search terms are clearly industrial and relevant
